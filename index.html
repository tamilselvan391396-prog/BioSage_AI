About BioSage AI

BioSage AI is an independent student learning project for Karpagam B.Sc. Biotechnology. It is not an official KAHE product and does not represent the college.

How answers work

Retrieval-augmented generation (RAG): find relevant source passages first, then ask the AI to explain them. Answers show source references where available.

Privacy

Uploaded papers and questions are sent to the configured AI backend for processing. Do not upload personal records or confidential exam materials without permission.

A live AI service requires an OpenAI API key, a vector store ID, and a deployed backend. Never paste an API key into this page or a public GitHub repository.
